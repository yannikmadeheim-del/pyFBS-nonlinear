============
Installation
============
pyFBS is supported on Python versions 3.5+. 


************
Dependencies
************

* PyVista
* pyansys
* numpy
* pandas


****
PyPI
****

:mod:`pyFBS` can be installed from PyPI using ``pip``:

.. code-block:: python

	pip install pyFBS

********
Anaconda
********
:mod:`pyFBS` can also be installed with ``conda`` run:

.. code-block:: python

	conda install -c conda-forge pyFBS


******
Source
******
The source code of the pyFBS can be also downloaded (cloned) by running:

.. code-block:: 

	git clone https://gitlab.com/pyFBS.git
	cd pyFBS
	python setup.py install
