============
Installation
============
pyFBS is supported on Python versions x.y+. 


****
PyPI
****

:mod:`pyFBS` can be installed from PyPI using ``pip``:

.. code-block:: python

	pip install pyFBS

********
Anaconda
********
:mod:`pyFBS` can also be installed with ``conda`` run:

.. code-block:: python

	conda install -c conda-forge pyFBS

************
Dependencies
************

* PyVista
* numpy
* pyEMA
