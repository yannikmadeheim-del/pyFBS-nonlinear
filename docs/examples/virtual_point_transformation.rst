==============================
Virtual Point Transformation
==============================
Lack of rotational degrees of freedom and non-collocated Dofs on the interface can be considered as most prominent systematic errors in FBS. 
Both of the above mentioned difficulties can be resolved using virtual point transformation (VPT). 
Based on interface deformation modes (IDMs) full-DoF virtual point's (VP's) admittance matrix is reconstructed with perfectly collocated DoFs for each substructure.
